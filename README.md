# Walmart Customer Service Compliance Assistant V1.1
沃尔玛售后客服合规助手。使用方法：选择或调用 Skill 后粘贴客户邮件、中文回复要求或已有英文草稿。可补充订单状态、已确认的物流安排及平台授权证据。无需填写固定表单。
示例：客户要求退回压缩床，但无法装回原包装。请生成英文回复，取件尚未确认。
迁移：支持 Agent Skills 的环境可使用 skills/walmart-customer-service-compliance/ 整个目录；支持插件 ZIP 的环境可导入完整 ZIP（具体取决于账号与客户端能力）；也可将 SKILL.md 内容作为自定义指令使用。此包不含账户数据、API 或实际退款/发送权限。政策需定期核实。

## Public distribution
This independent, unofficial skill is not affiliated with Walmart. Download the repository ZIP from GitHub (Code → Download ZIP), or use the skill directory in a compatible Agent Skills environment. All examples are anonymized; review current official policies before use.
